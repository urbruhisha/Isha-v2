# Bada Lee — Choreography Archive

A motion-focused website inspired by choreographer and dancer Bada Lee.

This project explores editorial web design, video-based storytelling, and interactive motion through a dark, minimal visual style.

## Live Website

[View the live project](https://urbruhisha.github.io/bdlee/)

## About the Project

I designed and developed this website as a personal web design project centered around Bada Lee's work and choreography.

The goal was to create an experience that feels more like a visual archive than a traditional informational website. The design uses large typography, video, scrolling interactions, and subtle motion to guide users through the content.

## Built With

- HTML
- CSS
- JavaScript

## Features

- Responsive layout
- Video-focused sections
- Scroll-based animations
- Interactive motion timeline
- Custom transitions and hover effects
- Minimal dark editorial design

## What I Practiced

This project helped me practice combining graphic design with front-end development, especially working with motion, layout, typography, and interactive JavaScript elements.
