# Genshin UI

A fan-inspired interface project based on the visual language and presentation style of Genshin Impact.

This project focuses on immersive UI design, motion, video, and interactive front-end development.

## Live Website

[View the live project](https://urbruhisha.github.io/genshin-ui/)

## About the Project

I created this project as a way to explore game-inspired web design and interactive presentation.

The site combines large visual sections, character-focused layouts, video, motion, and custom UI styling to create an experience that feels closer to a game interface than a traditional website.

## Built With

- HTML
- CSS
- JavaScript

## Features

- Game-inspired interface design
- Character-focused sections
- Video backgrounds
- Scroll-based interactions
- Custom animations
- Responsive layout
- Interactive UI elements

## What I Practiced

This project helped me practice translating game UI ideas into a working web experience.

I focused on layout, visual hierarchy, motion, video integration, and making the design feel immersive while still keeping the interface usable.
